## Lightning Web Components

| Bundle                                                                      | Exposed                                  | Job                                                                                                                                                 | Calls                                     |
| --------------------------------------------------------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| [`vkfOwnerWorkspace`](../../force-app/main/default/lwc/vkfOwnerWorkspace)   | Yes — tab and App Page (phone + desktop) | Shell: hero card, family picker, month stepper, section bar, **+** button, toasts; remembers last family and section per device                     | `getFamilies`; opens `vkfOwnerEntryModal` |
| [`vkfOwnerOverview`](../../force-app/main/default/lwc/vkfOwnerOverview)     | No                                       | Net worth, month KPIs with change vs last month, top categories, six-month trend, account cards, coming up, recent activity                         | `getOverview`                             |
| [`vkfOwnerLedger`](../../force-app/main/default/lwc/vkfOwnerLedger)         | No                                       | Month ledger: search (debounced), filter (All, Spending, Income, Transfers), day groups with daily net, void with confirmation, load more           | `getTransactions`, `voidTransaction`      |
| [`vkfOwnerDues`](../../force-app/main/default/lwc/vkfOwnerDues)             | No                                       | 7/30/90-day window, total due, overdue flags, one-tap pay for bills and EMIs                                                                        | `getDues`, `payDue`                       |
| [`vkfOwnerBudget`](../../force-app/main/default/lwc/vkfOwnerBudget)         | No                                       | Progress ring, pace against the calendar, per-category bars, spending without a budget                                                              | `getBudget`                               |
| [`vkfOwnerMembers`](../../force-app/main/default/lwc/vkfOwnerMembers)       | No                                       | Read-only member cards: role, status, lock, two-step, sessions, last sign-in                                                                        | `getMembers`                              |
| [`vkfOwnerEntryModal`](../../force-app/main/default/lwc/vkfOwnerEntryModal) | No (opened by the shell)                 | `LightningModal` form: Expense / Income / Transfer, large amount field, account, category with quick chips, date, payment mode, payee, member, note | `getEntryOptions`, `saveEntry`            |
| [`vkfOwnerLib`](../../force-app/main/default/lwc/vkfOwnerLib)               | No                                       | Shared helpers: money (en-IN), dates, months, Apex error text, JSON parse, safe storage, colours, ledger filter list                                | —                                         |
| [`vkfOwnerTokens`](../../force-app/main/default/lwc/vkfOwnerTokens)         | No (CSS only)                            | Design tokens and shared CSS primitives (cards, chips, rows, segmented control, skeletons, bars); imported by every stylesheet                      | —                                         |

Sections receive `family-id`, `month`, `currency-code` and `refresh-token` from the shell. Each loads its own data, and the shell bumps `refresh-token` after any change so the open section reloads.
